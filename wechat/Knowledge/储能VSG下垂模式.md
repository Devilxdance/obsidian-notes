# 从同步发动机的调速器与励磁特性学习储能VSG下垂模式（二）

# 前言

储能VSG功能，在上章节已经说明了与VSG功能息息相关的同步发电机的两个核心特性：惯量及阻尼特性，本章节将深入了解同步发电机的另外两个核心特性：调速器特性及励磁调压特性。与储能VSG的重要功能：下垂控制息息相关。

# 一、调速器特性

同步发电机中包含一个名为调速器的组件，说白了就是调节发电机组转子转速的器件，那它又是如何控制发电机组转速呢？先需要了解调速器由哪些组件组成：

- 转速采样单元：该单元可以实时采样转子的转速，并将其转化为电信号，方便信息传递。
    
- 控制单元：该单元在接受到转速信息后，根据预设的控制逻辑实时发送转速调整指令。
    
- 执行机构：油动机与配汽机构作为执行机构，实时接受控制单元指令进行阀门开闭及进汽动作，实现转速的调整。
    

通过这一套的执行逻辑，可以实现哪些作用呢？

## ①一次调频

一次调频变化趋势图（仅供参考）

一次调频是调速器的核心能力，最形象的比喻就是好比膝跳反应，在受到锤击时，膝盖会不自觉的弹起。该功能也是如此：当电网的负荷突然增加时，导致了电网频率突降，调速器会立刻加大阀门的开度，从而增加发电机组出力，反之负荷降低的调节方式也是一样。一次调频结束后，一般无法将电网频率恢复至正常的50Hz，仍会存在一些偏差，此时就需要二次调频恢复电网频率。

## ①二次调频

当一次调频后，电网频率仍无法恢复时，此时调度中心会根据实际频率差距情况，调用选定的发电厂，向调速器发送调度指令，调速器根据调度指令进行精准调频，直至电网频率恢复正常。

# 二、励磁调压特性

调速器特性调节的是有功功率和频率，而励磁特性，调节的是无功功率和电压。在发电机组中，有一个励磁线圈，该线圈会长期通直流电，产生一个固定的磁场。那么励磁线圈又是怎么做到无功及电压调节呢？

这里需要了解一下AVR励磁调节器。该调节器的作用是调节励磁线圈中直流电流的大小。调节过程如下：

- AVR增大励磁线圈中的直流电流时，转子的磁场会增加，磁场越强，则产生的无功功率以及机端电压就越高。
    
- AVR降低磁线圈中的直流电流时，磁场减弱，吸收电网的无功功率。
    

在实际电网运行时，励磁调压特性的作用又是什么呢？

## ①维持电网电压压稳定：深夜时，负荷会大幅度降低，此时电网电压会偏高，AVR励磁调节器检测到电压高时，会自动地减少励磁电流，从而使电网电压降低到额定值。

## ②电网时电压支撑：当电网遭到雷击等事故，导致发生短路故障时，电网会瞬间跌落，此时若AVR检测到电网电压跌落时，会立刻将励磁电压调大，从而强行把电网电压短暂支撑起来，避免了大范围的发电机停机扩大事故。

# 小结

储能VSG的下垂控制是使用PCS模仿同步发电机的调速器特性（P/F）与励磁特性（U/V）的特性，从而具备相同能力。下章将介绍储能VSG功能及其应用场景。

# 学习VSG前先了解同步发电机特性

储能VSG又称虚拟同步发电机，顾名思义就是储能系统去模拟同步发电机的特性。同步发电机，即火电、水电、核电等必备机组。那同步发电机具备哪些特性呢？

## ①转动惯量特性

同步发电机由转子和定子组成，而发电厂发电机组的转子一般重量很重，在高速旋转时会产生强大动能，此时想要减速时，会有惯性保持一定速度持续旋转。就像一个大货车在刹车时，不能第一时间刹住车，在加速时不能第一时间提速。

那这个特性在实际电网运行中起到什么作用呢？

- 在电网的负荷突然上升时（如用电高峰期生产设备同时开机），此时会导致发电机的有功功率增大，转子速度下降，此时由于惯量特性，转子速度会缓慢下降，在此过程中，发电机组有足够时间增大转子驱动力，从而恢复电网稳定。若无惯量特性，负荷突然上升时，转子速度会瞬间跌落，导致电网瘫痪。
    
- 当电网的负荷突然下降时，原理与上面一致，这里不做赘述。

## ②阻尼特性

发电机阻尼的特性来源于转子表面埋了一圈金属阻尼条，专业名词“阻尼绕组”可以在某度上搜索图片，加深理解。那这个阻尼绕组的特性是什么呢？汽车减震器是一个很形象的比喻，当路面出现看坑洼时，装了减震器的车会阻止车身猛烈晃动，从而平稳的过坑。阻尼绕组也是一样，转子受电网扰动想要发生变化时，阻尼绕组会产生反方向的力，去阻止转子发生变化。

那这个特性在实际电网运行中起到什么作用呢？

提升发电机组抗干扰性：当电网发生故障（短路等），此时发电机转子会出现时快时慢的情况，专业名词是“低频振荡”。导致发电机的频率与电网的频率不一致，当达到一个范围时，发电机组将彻底停机。当配备了阻尼绕组，转子产生时快时慢的变化时，阻尼绕组会产生相反的力去阻止转子变化，再几个回合后，振荡会逐渐平稳直至发电机频率与电网频率彻底一致，发电机组稳定运行。

抑制次同步谐振：首先需要搞明白什么是次同步谐振，可以简单理解为远距离输电时，电网由于无功补偿设备的增多，出现了一个10~50Hz的频率，这个频率会影响发电机组，导致汽轮机与转子连接的轴来回拉扯，当超过金属疲劳度时，会发生断裂的情况。此时阻尼绕组通过其产生反作用力的特性，阻止变化。从而保证发电机组的正常运行。
