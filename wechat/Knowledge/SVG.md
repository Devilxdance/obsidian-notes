# 读懂什么是SVG？

SVG静止无功发生器（专治三相变压器单相负载不平衡）


![[Pasted image 20260805214031.png]]
一、什么是SVG

全称静止同步补偿器，有源电力电子补偿设备，内部IGBT模块，不靠电容电抗投切，三相独立分相控制，一台设备同时实现：无功补偿+三相不平衡治理+谐波抑制。

二、治理单相负载不平衡核心原理（Dyn11配电变4线制专用）

1. 实时采集A/B/C/N三相电流、电压，分解负序、零序不平衡电流（单相偏载全部产生零序电流，零线发热根源）；

2. 三相桥臂独立输出反向补偿电流：重载相输出感性电流降低负荷等效电流，轻载相输出容性电流抬高等效电流；

3. 通过内部直流母线相间转移有功功率，把偏载负荷在线“均分”到三相；

4. 抵消零序电流，大幅减小零线电流，解决中性点漂移、电压高低不均问题。

关键性能

- 响应速度：5～10ms，负荷突变瞬间跟上；

- 治理效果：三相不平衡度可压至≤5%（国标限值10%）；

- 四线制SVG带独立中性支路，专门适配居民台区大量220V单相负载。

三、400V配电变压器SVG接线（三相四线制）

1. 主回路接线（变压器低压出线侧并联）

SVG端子：A黄、B绿、C红、N蓝、PE黄绿接地

1. A/B/C分别接变压器低压L1/L2/L3；

2. N端子必须接入变压器中性零线（治理不平衡的关键，三线SVG不能处理零序不平衡）；

3. PE可靠接配电室接地排，接地电阻≤4Ω；

4. 串联塑壳断路器做设备保护。

2. 采样CT接线（重中之重，接错补偿失效）

1. CT装在变压器总出线（SVG上游，采集全部负载电流）；

2. CT一次P1进、P2出；二次S1、S2对应接入SVG采样端子；

3. CT二次严禁开路，布线和动力电缆分开防干扰；

4. 4线不平衡场景必须采集三相+零线四路CT。

四、针对变压器单相不平衡的现场作用

1. 消除电压偏移

避免一相200V、两相245V烧家电，三相电压压差控制在±5V内；

2. 降低变压器温升

零序磁通大幅减少，绕组、铁芯发热减轻，延长变压器寿命；

3. 零线不再发热

不平衡零序电流被SVG抵消，零线载流量骤降，杜绝零线烧断起火风险；

4. 降低变压器损耗

三相电流均衡，铜损、铁损下降，减少电费损耗；

5. 改善计量、保护不误动

三相电流接近相等，三相四线电表计量准确，过载、漏保不再频繁误跳。

五、容量选型（台区单相不平衡简易算法）

1. 测三相最大电流差值ΔI；

2. SVG不平衡治理容量≈ΔI × 0.4kV × √3 ÷1000；

3. 同时兼顾无功需求，最终容量取两者最大值，优先选四线型SVG。

举例：变压器三相电流A=200A，B=60A，C=50A，差值140A，不平衡容量≈97kvar，选100kvar四线SVG。

六、使用注意事项

1. 台区优先人工均分负荷，SVG做兜底治理，不能完全替代前期布线均分；

2. 零线主线不能取消、不能装熔断器，中性点接地必须完好；

3. 谐波大的商铺/充电桩台区选SVG+APF一体机，同步滤波；

4. 设备断电后内部直流电容需放电5分钟以上再检修；

5. 户外台区选用IP54防护柜体，做好散热防尘。
