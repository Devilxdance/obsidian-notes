# 【致知—PCS】浅谈AC800V 储能变流器的应用

# 一、引言

在SNEC2026上海光伏展上，看到英博智储展示了AC 800V储能变流器；据沟通，其主要面向海外中小型地面光伏电站配套储能应用。目前，光伏逆变器普遍采用AC 800V输出，而储能电站用PCS交流侧输出为690V，标准的光储交流耦合方案为在10kV/35kV侧实现耦合。为了提升光伏——>储能的能量链路效率，部分PCS企业推出在AC800侧交流耦合方案，当光伏发电给储能充电时，可以提升至少2%的充电效率。该方案相比中压交流耦合是有明显的效率优势，那该方案存在的不足呢？大家都没有提及，学生给大家分析一下。

# 三、AC 800V PCS允许的最低直流电压高于AC690V的原因

目前储能变流器主流采用三电平NPC/ANPC拓扑，对于最低直流电压的要求为：直流侧电压必须高于交流侧线电压峰值。线电压峰值和直流侧电压关系如下：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/AwbsXcAibfCEiaZ1JZq3oMV52GWPUBMh2UPAfqBQGmXJfTtNVgDWR7VlgR4t3Mq4XFt7qTZY5j6PWrXvRxIf1vsMOKEIKAZicLnibtDib9X2wvVQ/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)

注1：储能变流器输出侧为星形连接，线电压=√3相电压；

注2：三电平 NPC/ANPC 拓扑的直流母线由两个电容串联组成，总电压为Vdc，因此上下电容的电压各为Vdc/2，直流母线中点电位为 0；

注3：m为调制比；由于SVPWM直流侧电压利用率高（比SPWM高15.47%），是目前主流的调制方式，其线性调制区最大调制比约为1.1547（2/√3）。

对于AC800V输出的PCS，其线电压峰值为：880V*√2≈1244V，故：

![图片](https://mmbiz.qpic.cn/mmbiz_png/AwbsXcAibfCELHhQm5CfeAf2XgMCW9VMJ8aTiaA0hhwmo6me8yOU5CWHlzb6d27icSDJMYwAAlOQhKMWoSx5g9DEic3PfSW5DGcb5hyXeSe45jw/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=3)

考虑到开关压降、系统压降、谐波含量控制、安全余量等因素，AC 800V PCS直流侧最低电压标注为1150V左右。

接下来还有一个问题，当电网电压+10%波动时，此时直流侧电压仅有1150V时怎么办？

答案就在直流侧电压和线电压峰值的公式里，当线电压为880V而直流侧电压为1150V时，调制比m≈1.25（已然超过线性调制区最大调制比1.1547）。

如下图：

- 线性调制区：m≤1.1547，合成的电压在内切圆范围内；
    
- 过调制区Ⅰ：1.1547
    

过调制区Ⅱ：1.212

当m1=1.25时，处于过调制区Ⅱ，此时输出电压谐波含量上升，个人猜测估计还能满足电网约定要求（≤5%）。

# 四、PCS直流侧最低电压为1150V，能否匹配现有系统？

目前磷酸铁锂电池系统主流PACK规格为1P52S、1P68S、1P104S，那么对应DC1500V电池簇的规格为：

- 1P52S*8：1P416S，额定电压为1331.2V
    
- 1P68S*6：1P408S，额定电压为1305.6V（主要为阳光电源）
    
- 1P104S*4：1P416S，额定电压为1331.2V（最常见）
    

按1P416S的电池簇，DC1150V对应的电芯电压为：2.7644V。

此外，学生了解了下部分储能电芯企业，其主流314Ah电芯在0.5P倍率充放电情况下的电压上下限为：

![图片](https://mmbiz.qpic.cn/mmbiz_png/AwbsXcAibfCHibPXuAVAUBN0Kr8cAJsIVLWTHL8cbA2o9zWbKRFdMBStNvia5PYLdWlGtRHqQyiarXHKe64z6lNsibUiatMz00hsPMHOCY0k0Zbss/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=5)

那么可以看到，在采用AC800V储能变流器时，要想储能系统实现满充满放，对电芯的品牌选型是有限制的，比如采用上述企业A和企业B的电芯成簇，可以配套AC800V储能变流器应用而不损失容量；当采用企业C和企业D的电芯成簇时，若需要满足AC 800V PCS的电压范围要求，要么重新标定SOC为0%时的电压值，要么实际使用时限制SOC下限。

上面说的都是正常使用的工况，那么对于非正常工况呢？如：

# 1、SOC差异大时，如何进行SOC标定？

随着储能系统运行时间的增加，由于安时积分法的累计误差越来越大，需要对储能系统进行一次满充满放，以强制校准SOC；大多BMS的SOC标定条件为：充电时充至二级告警，强制校准SOC为100%；放电时放至二级告警，强制校准SOC为0%。若采用AC800V PCS，BMS对应的三级告警阈值是否合理？是否能满足SOC标定的条件，这个需要重点考虑。

# 2、当电池簇电压低于1150V时怎么办？

若电池系统长时间静置不用，导致电池系统电压低于1150V，如电池簇电压跌到1050V，此时AC 800V PCS无法工作，需要额外配置充电机将电池簇的电压充至1150V以上。相比AC690V PCS，AC800V对电池簇的长时间静置容忍度更小。或许，许多人可能会认为实际使用的时候基本不会出现这种情况，所以没必要纳入考虑。但真的出现了呢？出现后的补电成本、停电的损失、客户的投诉；在产品设计初，就得考虑到这个问题。

那如何解决该问题？

1、采用双极拓扑，即增加全功率段DCDC：

增加DCDC后，PCS成本增加不说，运行效率还会下降0.5%~1%，那如何宣传AC800V交流耦合所带来的效率优势？❌

2、增加旁路DCDC：

可以在PCS内部增加旁路DCDC；当电池电压高于1150V时，DCDC旁路；当电池电压低于1150V时，投入DCDC；而且该DCDC功率可以是PCS功率的10%~20%。该方案相比方案1，不仅成本低，而且效率更高。✅

综上来讲，若AC800V PCS仍采用单极拓扑，并不匹配现有DC1500V电池系统；忽视其拓扑本身的缺陷去大肆宣讲方案的优势（对缺陷闭口不提），完全是在伤害行业的发展。
