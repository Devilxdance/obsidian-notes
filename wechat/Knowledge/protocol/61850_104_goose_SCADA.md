

简单画一个储能电站通信架构：

```
                 电网调度中心
                     |
                IEC 104
                     |
             ┌────────────┐
             │  EMS/AGC   │
             └────────────┘
                     |
              IEC 61850
                     |
        ┌────────────────────┐
        │  变电站自动化系统   │
        │     (SAS)          │
        └────────────────────┘
          |        |        |
       GOOSE    MMS     SV
          |        |
       保护信号  状态监控

          |
   ------------------
          |
       PCS
          |
       BMS
          |
       电池簇
```

简单理解：

|协议|解决什么问题|典型对象|
|---|---|---|
|IEC 61850|变电站设备之间统一通信标准|保护、测控、PCS、EMS|
|GOOSE|IEC61850里面的高速保护报文|断路器跳闸、联锁|
|IEC104|电站和电网调度通信|AGC/AVC、遥测遥控|

关系：

> **GOOSE 是 IEC61850 的一个子协议**
> 
> **IEC104 和 IEC61850 是平级关系，主要负责不同方向通信**

# 2. IEC 61850 是什么？

IEC61850本质：

> 一个用于电力自动化系统的通信标准。

以前变电站：

```
保护装置A
  |
厂家私有协议
  |
RTU
  |
厂家协议
  |
后台
```

不同厂家互不兼容。

IEC61850以后：

```
保护
测控
PCS
开关柜
计量

全部通过IEC61850通信
```

---

## IEC61850包含哪些东西？

主要三个：

### ① MMS

Manufacturing Message Specification

用于：

- 状态读取
- 参数设置
- 遥测

类似：

```
EMS读取：

PCS有功功率？
SOC？
运行状态？
```

速度：

几十ms~秒级

---

### ② GOOSE

重点。

GOOSE = Generic Object Oriented Substation Event

中文：

**面向通用对象的变电站事件**

用途：

高速事件。

例如：

10kV母线短路：

```
保护继电器检测故障

       |
       |
     GOOSE

       |
       ↓

PCS停止
断路器跳闸
消防联锁
```

要求：

毫秒级。

典型：

```
保护装置
    |
    | GOOSE
    |
断路器
```

不是用来传SOC、功率这些数据的。

---

### ③ SV

Sampled Value

采样值。

用于：

高速电流电压采样。

例如：

传统：

```
CT/PT
 |
模拟量
 |
保护装置
```

IEC61850：

```
电子式互感器

 |
SV

 |
保护装置
```

速度非常快。

储能PCS一般很少直接用SV。

结合你们：

建议产品通信接口：

### 标配

✅ Modbus TCP  
✅ Modbus RTU  
✅ CAN  
✅ MQTT  
✅ IEC104（可选）

### 高端版本

增加：

✅ IEC61850 server

用于：

- 德国VDE项目
- 工商业微网
- 电网公司项目

### GOOSE

一般不要集成到标准柜。

原因：

它不是储能产品功能，而是：

> 电站保护系统功能。

通常由：

- PCS厂家
- 保护厂家
- EPC

联合完成。

---

一句话总结：

> **CAN解决“电池内部”，Modbus解决“设备之间”，IEC61850解决“变电站设备之间”，GOOSE解决“保护快速动作”，IEC104解决“电站和电网调度之间”。**
> 
> **普通工商业储能：Modbus+CAN足够；MW级电网储能：IEC104+IEC61850+GOOSE基本成为标准配置。**

如果从你们做 **5MWh集装箱出口欧洲（德国/意大利/英国）** 的角度，还需要进一步看 **IEC61850在BESS PCS中的具体接口要求（Logical Node：MMXU、ZBAT、DRCC、GGIO等）以及EPC招标文件如何写**，这个对海外项目非常关键。

一句话总结：

> **BMS管电池，PCS管能量转换，EMS管运行策略，SCADA管监控，IEC61850管变电站设备，IEC104管电网调度，MQTT管云端运营。**

对于你们现在做欧洲 **261kWh柜 / 5MWh Container**，产品竞争力排序其实是：

**Modbus + CAN（必须） → MQTT Cloud（强烈建议） → IEC104（项目型） → IEC61850（电站级） → GOOSE（保护级）**

这个顺序最符合市场。


**SCADA读取到故障信息 ≠ SCADA参与保护动作。**

在大型储能电站中，保护动作通常由：  
**保护继电器 + GOOSE / 硬接点 / 保护逻辑** 完成；  
或者由 **PCS自身保护逻辑** 完成。

SCADA即使看到故障，也通常只是“显示、报警、记录”，不会作为保护闭锁或跳闸依据。

**电网调度通常不会经过 SCADA 再到 EMS。**

常见架构是：

**调度中心 → IEC104 → EMS/PPC → PCS**

**SCADA 是并列的监控系统，通过 IEC61850/Modbus 等采集设备信息，不是 EMS 的下一级。**
