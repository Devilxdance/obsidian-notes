
# 二、重点：标准工作流程（"建模—验证—审核—入库"）

![[Pasted image 20260730221828.png]]
发电建模标准工作流程

下面把每一步讲明白，谁来做、做什么、产出什么。

# 1.收资（业主牵头，设备商 / 检测机构配合）

向设备制造商、并网检测机构索取资料；厂家提供不了的，业主要把掌握的资料都补齐。核心是：场站基本信息、电气一次接线图、各设备参数、保护定值、控制策略说明、电磁暂态封装模型及说明书、型式试验报告与数据。

# 2.控制器半实物测试（试验研究单位，RT-LAB）

把真实控制器接入仿真机，构成"真实控制器 + 虚拟主电路"闭环，在三相对称 / 两相不对称下做高电压穿越、低电压穿越、高低电压连续穿越等工况，输出 .mat 录波数据（采样率≥10kHz）。这份数据是所有模型校核的"标尺"。

# 3.单机机电建模（试验研究单位，PSASP）

搭建风电 / 储能 / 光伏单机无穷大系统模型。关键动作是参数辨识：以半实物高低穿曲线为基准，用最小二乘法加优化算法（如蛇优化算法）拟合无功 / 有功电流系数、阈值电压、电流设定值等，再与半实物数据对比，确认偏差达标。

# 4.单机电磁建模（设备商提供封装库，试验单位校核）

设备制造商须交付电磁暂态封装模型：统一接口规范、提交 Windows + Linux、32位 + 64位 的静态库（.lib/.a）与动态库（.dll/.so），二次控制保护模型须与现场一致。厂家做不了的，改做电磁暂态结构化模型。ADPSS 仿真结果与半实物对比校核。

# 5.场站详细模型 + 等值模型（机电 PSASP + 电磁 ADPSS）

等值聚合。详细模型 1:1 还原场站（所有变流器、箱变、集电线路、主变、等值阻抗）；等值模型遵循"等值前后损耗不变、运行方式一致"原则，同类设备分群聚合、按馈线聚合。整站详细与等值模型必须一致性校核通过。

# 6.误差分析 + 报告撰写 + 审核入库

按 GB/T 32892、GB/T 44117、NB/T 31053 分段计算稳态 / 暂态偏差，对照允许值表判定合格（储能例：电压≤0.02/0.05、电流≤0.10/0.20 等）。形成机电 + 电磁建模报告（含波形对比、偏差计算、参数卡、封装库接口信息表），须有资质机构验证并加盖公章，再进入省调初审、网调复审、备案、PGDB 入库。

# 三、顺带说清：业主找谁配合、怎么验收

既然是标准流程，业主作为责任主体，要清楚"拉谁入伙"和"怎样算过关"。

要找这些人配合

|   |   |
|---|---|
|角色|职责|
|设备制造商|交付控制策略、电磁封装模型、设备参数、型式试验数据|
|并网检测机构|做并网型式试验，出具报告与数据|
|试验研究单位|半实物测试、建模、参数辨识、出报告（如武汉隆泰恒发）|
|调度机构|初审、复审、备案、监督考核|
|省级电科院 / 中国电科院|PGDB 平台填报与审核入库|

验收要过"四关"

|   |   |
|---|---|
|验收关|判定要点|
|① 成果文件|机电 / 电磁报告（盖章）+ 全部模型 + 封装库 + 半实物数据|
|② 技术偏差|模型与半实物偏差满足允许值；等值模型一致|
|③ 流程闭环|通过初审复审，取得 PGDB 入库凭证并备案|
|④ 合规时限|并网前1月提交、并网后6月入库，未被"两个细则"考核|

一句话总结

发电建模不是"写个报告交差"，而是收资 → 半实物校核 → 机电/电磁建模 → 误差分析 → 审核入库一条闭环。

模型入不了库，绿电就上不了"放心网"。
