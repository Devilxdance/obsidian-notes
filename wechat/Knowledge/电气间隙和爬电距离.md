
# IP67‑PACK 内部 DC1500V 电气间隙 & 爬电距离

> 标准依据：**IEC62619 / IEC63056 储能电池包，引用 GB/T16935.1‑2023 (IEC60664‑1)**
> 
> 重点：**IP67≠PD1**；PACK 内部昼夜温差会产生**内部凝露**，行业统一按 **污染等级 PD2** 设计，不是 PD3。
> 
> 过电压类别：PACK 内部直流回路，**过电压类别 II**；海拔＞2000m，**只修正电气间隙，爬电距离不变**。
> 
> 外壳是金属，PACK 外壳接地；人不能打开 PACK，但是外壳是可触及导电件。

## 绝缘类型怎么在 PACK 内部区分

1. **基本绝缘**：高压带电 ↔ 高压带电（PACK 内部，人接触不到）
    
    - DC+ ↔ DC‑；模组之间高压铜排；高压 BMS 功率回路之间
    
2. **加强绝缘**：高压带电 ↔ **接地金属外壳 / 接地金属结构件 / SELV 低压 BMS 采样控制电路**
    
    - 高压铜排到 PACK 壳体；高压母线到 BMS 低压采样板；高压到液冷金属板
    

> ⚠️ 即使外壳 IP67 密封，金属外壳是可触及接地导体，**高压对地必须加强绝缘**。

## DC1500V，PACK 内部 PD2，过电压类别 II，海拔≤2000m

PCB 常用 FR4，材料组别 **IIIa（CTI175‑400）**

表格

|绝缘类型|电气间隙 (mm)|爬电距离 (mm，IIIa PD2)|应用位置|
|---|--:|--:|---|
|基本绝缘|7|16|DC + 与 DC‑、高压铜排之间、模组高压之间|
|加强绝缘|14|32|高压→金属壳体；高压→BMS 低压控制采样回路|

> 如果 PACK 内部用高 CTI 环氧 / BMC（材料组别 I）：
> 
> ‑基本爬电 10mm；加强爬电 20mm。

### 海拔修正示例（仅电气间隙）

- 海拔 3000m，系数 1.2：基本间隙 = 7×1.2=**8.4mm**；加强 = 14×1.2=**16.8mm**
- 海拔 4000m，系数 1.4：基本间隙 = 9.8mm；加强 = 19.6mm

> 爬电距离永远保持 16/32mm，不随海拔放大。

## 工程实战注意点（PACK 非常容易踩坑）

1. **IP67 只是阻挡外部灰尘水汽，阻止不了 PACK 内部凝露**，绝对不能按 PD1 取值，认证机构全部按 PD2 评判。
2. 铜排边缘尖角、毛刺会降低实际有效电气间隙；铜排要倒圆角。
3. 沟槽 / 缝隙宽度＜1mm，不能计入爬电路径；绝缘隔板要做足够宽度，不能只靠一条窄缝绕。
4. BMS 采样板：高压采样点对 BMS 24V/3.3V 低压侧，**必须加强绝缘 14mm 间隙 /32mm 爬电**。
5. 金属液冷板：如果液冷板接保护地，高压铜排到液冷板按**加强绝缘**；液冷板悬浮不接地，按基本绝缘（不推荐悬浮）。
6. 系统最高电压：低温开路电压会到约 1650V，很多储能 PACK 会直接按 DC1650V 插值放大距离，留认证裕量。

## 快速工程取值（直接画图用，含裕量）

- 内部高压之间（基本）：**电气间隙≥8mm，爬电≥18mm**
- 高压对地壳 / 低压 BMS（加强）：**电气间隙≥15mm，爬电≥35mm**
# DC1500V 储能 PACK（IP67，海拔 4000m）

## 结构 / 硬件工程师设计检查清单（直接可用）

### 一、设计前提

- 系统电压：DC1500V
- 污染等级：**PD2**（IP67 内部凝露，不按 PD1）
- 过电压类别：II
- 海拔：**4000m**，电气间隙修正系数 **1.4**
- 绝缘材料：PCB FR4（IIIa）
- 外壳、液冷板、支架均为**接地金属**
- 格式：电气间隙 / 爬电距离（mm）

---

## 二、各部位最小设计值（已做海拔修正）

### 1）基本绝缘（高压 ↔ 高压）

1. 铜排 / 软排正负极之间：**≥9.8 / 16**
2. 模组高压极耳之间：**≥9.8 / 16**
3. 高压连接器内部端子之间：**≥9.8 / 16**
4. BMS 高压采样走线之间：**≥9.8 / 16**
5. 高压对内部不接地悬浮金属件：**≥9.8 / 16**

图纸推荐裕量值：**≥10 / 18**

---

### 2）加强绝缘（高压 ↔ 接地外壳 / 低压 BMS）

1. 高压铜排 → PACK 接地金属壳体：**≥19.6 / 32**
2. 高压铜排 → 接地金属液冷板：**≥19.6 / 32**
3. 高压铜排 → 接地金属支架 / 结构件：**≥19.6 / 32**
4. 高压回路 → BMS 低压控制 / 采样 / 通讯区：**≥19.6 / 32**
5. 高压连接器端子 → 连接器接地外壳：**≥19.6 / 32**
6. 模组高压极耳 → 模组接地金属外壳：**≥19.6 / 32**

图纸推荐裕量值：**≥20 / 35**

---

## 三、设计强制要求

1. 仅**电气间隙**随海拔放大，**爬电距离不变**
2. 铜排边缘倒圆角 **R≥1.5mm**，禁止尖角
3. PCB 隔离槽宽度 **≥1mm** 方可计入爬电距离
4. 振动、装配公差、热胀偏移需在裕量内消化
5. 三防漆不建议私自减小爬电距离，认证需单独评估
6. 内部金属件尽量全部接地，避免悬浮电位

---

## 四、图纸标注极简版（直接复制）

- 高压 - 高压：电气间隙≥10mm，爬电距离≥18mm
- 高压 - 接地外壳 / 低压 BMS：电气间隙≥20mm，爬电距离≥35mm
- 适用：IP67 电池 PACK，DC1500V，海拔≤4000m，污染等级 PD2
