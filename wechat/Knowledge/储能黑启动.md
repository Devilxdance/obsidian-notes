# 前言

黑启动，很多刚入行小伙伴对这个名词很陌生，感觉很高大上，在技术交流时经常会听到“这个PCS支不支持黑启动？”，会感觉到很迷茫。本文将以图文结合的方式并用通俗语言对黑启动概念、启动逻辑及优势进行详细叙述，希望大家读后有所获益。

# 一、先了解黑启动是什么
![[Pasted image 20260714115105.png]]
储能黑启动拓扑（仅供参考）

大家可以想象一个场景：一个城市的供电因极端天气或者重大故障导致电网瘫痪，此时所有的用电设备全部断电，包括电网供电的主力军：火电厂等机组全部停机。整个城市一片漆黑；在这个状态下从0到1恢复电网正常状态的过程就是黑启动。

所谓黑启动，就是不依赖外界电网供电，纯粹依靠系统自身自启动能力，通过系统内自启动电源，如小型发电机组、水电机组以及储能系统等。这些电源启动后，给火电机组供电，直到慢慢恢复电网供电的过程。

# 二、储能黑启动运行时序

![[Pasted image 20260714115116.png]]
储能黑启动启动时序图（仅供参考）

下面将介绍黑启动运行时储能系统各部件的动作时序：

## ①故障决策阶段

当电网调度系统发现电网出现大规模停电，电压、频率等数据全部归零时，将迅速切断所有负荷侧的电网开关，保证此时电网处于孤网状态。再向备案的具备黑启动能力的储能电站下发黑启动指令。

## ②黑启动准备阶段

储能电站在电网出现故障后，UPS将保持储能系统、PCS等设备控制电不掉电，储能系统由并网运行状态调至故障停机状态。并迅速切断并网断路器，待自检后切换至待机模式。

## ③黑启动阶段

当储能系统接收到电网调度中心的黑启动信号时，立即运行至VF模式，当PCS侧建立稳定电压后，此时储能系统的辅助供电切换至自供电代替UPS并启动液冷机组等设备保证储能系统正常运行；EMS同步将储能系统交流侧断路器闭合，并将火电厂的断路器开关闭合，此时火电厂控制电恢复。火电厂逐步启动并输出电能，此时需要储能系统和火电厂输出的电压、频率、相位等完全一致，同期并网运行。

## ④全网恢复阶段

利用刚刚复苏的火电厂产生的电能，为其他大型火电厂、水电厂做电能支撑，启动并同期并网运行，此时所有火电厂等电网供电主力军全部恢复，主电网正常运行。

## ⑤负荷恢复供电

当电网完全恢复后，电力调度系统按照负荷重要性逐步分级恢复供电，待所有负荷正常恢复后，储能系统退出黑启动模式。

# 三、储能黑启动和其他黑启动区别

|对比维度|储能黑启动|水电黑启动|柴油 / 燃气轮机黑启动|火电互启|
|---|---|---|---|---|
|启动前提|不需要外部电源|无需外部电源|无需外部电源|需要另一个火电机组|
|响应速度|启动速度快，秒级电压输出|开机流程长，约十几分钟|启动需要预热，约5～15 分钟|等待邻厂送电，恢复周期最长|
|**持续供电能力**|受制于电池容量|可持续输出|可持续输出|可持续输出|
|**场站选址**|1. 火电厂区内（带厂用电启机）2. 城市枢纽变电站（电网侧独立黑启动）|必须临近河流、水库，选址受限|厂区、变电站均可，占地大、噪音大|仅大型火电集群内部适用|
|**日常复用价值**|闲时可进行调峰调频、电力市场交易等；|无收益|无收益|无额外辅助服务收益|
|**核心短板**|电池有充放电时长限制|选址受限水文条件|运维较贵，噪音污染严重|没有自供电能力|
