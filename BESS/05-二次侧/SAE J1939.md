# SAE J1939

> CAN 提供通信基础，通信协议提供对话语言

---

## 概述
- 基于 CAN 2.0B 的高层通信协议
- 由 SAE (Society of Automotive Engineers) 制定
- 广泛应用于商用车、工程机械、发电机组等领域
- 29-bit 扩展标识符，支持 PGN (Parameter Group Number)

## 协议栈
- 物理层：CAN 2.0B (250 kbps 典型)
- 数据链路层：29-bit ID + 8 字节数据
- 应用层：PGN + SPN (Suspect Parameter Number)

## 在储能中的应用
- BMS 内部电芯/模组通信
- PCS ↔ BMS 状态交互
- 发电机组 / 微网设备互联
