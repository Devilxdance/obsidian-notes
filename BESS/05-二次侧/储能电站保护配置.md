# 储能电站保护配置

## 保护分区 (由内向外)
1. **电池侧保护** (BMS 承担)
   - 单体过压/欠压/过温
   - 绝缘监测
2. **直流侧保护**
   - 直流过流 / 短路
   - 直流接地
3. **PCS 保护**
   - IGBT 过流 / 过热
   - 直流母线过压
   - 交流过流 / 过压 / 欠压
   - 频率异常
   - 孤岛检测
4. **变压器保护**
   - 差动保护 (≥8MVA 或重要)
   - 瓦斯保护 (油变)
   - 高压侧过流
5. **并网点保护**
   - 并网开关柜保护
   - 低电压 / 过电压
   - 低频 / 过频
   - 逆功率 (如有要求)

## 典型配置表

| 保护对象 | 主保护 | 后备保护 | 异常告警 |
|---------|--------|---------|---------|
| 电池 | BMS | BMS | SoC 越限 |
| 直流 | 熔断器+直流断路器 | — | 绝缘降低 |
| PCS | 本体保护 | AC 断路器 | 温度高 |
| 变压器 | 差动/速断 | 过流 | 温度/过负荷 |
| 并网点 | — | 低压/低频 | 电能质量 |
