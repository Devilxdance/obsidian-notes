# 通信协议概览

> 🔴 **重点学习领域**

---

## 协议层次图
```
调度层:  IEC 104  ─── 远动机(RTU) ─── 调度数据网
站控层:  IEC 61850  ─── 综自后台 / SCADA
         Modbus TCP
间隔层:  GOOSE / SV (61850)
         Modbus RTU / CAN
设备层:  CAN / RS485  ─── BMS, PCS, 电表...
```

## 各协议详解

### Modbus
- RTU (RS485) vs TCP
- 主从架构，简单可靠
- 储能中最常用 (PCS ↔ EMS, 电表, 空调...)
- 局限：速度慢，安全性弱，无时间戳

### IEC 61850
- 变电站自动化标准，储能正在过渡中
- **MMS**：站控层通信 (后台 ↔ IED)
- **GOOSE**：间隔层快速信号 (保护联闭锁)
- **SV**：采样值传输 (替代传统 CT/PT 接线)
- SCL 配置文件 (ICD / CID / SCD)
- 应用：新一代储能电站，尤其大储

### IEC 104 (IEC 60870-5-104)
- 远动通信协议
- 储能电站 ↔ 调度主站
- 四遥：遥测、遥信、遥控、遥调
- 信息点表

### DNP3
- 北美主流，类似 IEC 104
- 国产设备中较少


### 菊花链（Daisy Chain）
- BMS 电芯监控单元间级联通讯
- SPI 透传，无需每节点 MCU，成本低
- 典型芯片：ADI 6804 / 6811，NXP，TI
- 📖 详细 → [[菊花链通讯]]

### CAN
- BMS 内部通信 (CAN 2.0B)
- PCS ↔ BMS (CAN)
- 速度快，实时性好
- 上层协议：[[SAE J1939]]

---


### MQTT
- 发布-订阅模型的轻量级物联网协议
- QoS 0/1/2 三级消息质量
- Broker 架构实现时空解耦
- BESS 场景：云端监控、告警推送
- 📖 详细 → [[MQTT 协议基础]]

## 选型思路
- 工商储小项目 → Modbus TCP/RTU 足够
- 大储 / 调度要求 → IEC 104 + 61850
- BMS 内部 → CAN
