## 1. IEC 61850 简介

- **全称**：International Electrotechnical Commission 61850
- **定位**：电力系统自动化通信网络与系统的国际标准
- **核心应用**：变电站自动化，正逐步扩展到储能、新能源等分布式能源领域
- **核心思想**：面向对象的数据模型 + 标准化的配置语言（SCL），为不同厂商 IED 设备提供统一的互操作框架

### 三大关键技术

| 技术 | 说明 |
|------|------|
| 面向对象数据模型 | 利用统一的逻辑节点（LN）、数据集（DataSet）和通信服务定义设备功能 |
| 自描述配置语言（SCL） | 通过 XML 描述整个系统的配置，实现设备即插即用 |
| 通信服务映射 | 包括 MMS、GOOSE、SV，满足不同场景的实时性和数据量要求 |

---

## 2. 应用场景

- **数字化变电站**：从过程层到间隔层再到站控层的全链路信息交换，提升自动化水平和运行可靠性
- **分布式能源管理**：扩展到风电、光伏、水电等系统，实现现场数据采集、监控和保护
- **智能电网与数据中心**：引入数据中心电源管理、微电网控制，实现自动切换、故障诊断和远程监控

---

## 3. 应用设备

- **IED（智能电子设备）**：保护继电器、控制器、测量设备、合并单元等，通过统一数据模型实现互联互通
- **通信网关与交换机**：基于以太网和 TCP/IP，用于传输 MMS、GOOSE、SV 消息
- **配置与管理平台**：利用 SCL 文件实现系统配置、设备接入、数据模型自动识别

---

## 4. 解决的问题

- **设备互操作性**：标准化数据模型和配置语言，使不同厂商设备无缝互联
- **减少硬接线**：GOOSE 替代传统控制电缆，SV 替代 CT/PT 二次接线，大幅减少铜缆用量
- **实时通信**：满足保护（<4ms）、控制、监控等不同实时性需求
- **系统维护**：自描述配置使升级、改造、维护更高效

---

## 5. 三种通信方式

### MMS（Manufacturing Message Specification）

- **模式**：客户端—服务器（Client-Server），基于 TCP/IP
- **用途**：设备配置、监控、控制指令和状态信息交换
- **特点**：
  - 标准化通信：统一数据模型和服务接口
  - 可靠性高：TCP/IP 保证数据完整
  - 适用范围：配置、管理、报警、周期性监控数据
- **类比**：HTTP 式的请求-响应模型

### GOOSE（Generic Object Oriented Substation Events）

面向通用对象的变电站事件
-通用对象：变电站的智能设备
-事件：跳闸、合闸、状态
- **模式**：发布者—订阅者（Publisher-Subscriber），以太网多播
- **用途**：变电站内快速事件传输（保护跳闸、联闭锁、自动重合闸等）
- **特点**：
  - **实时性强**：可在 4ms 内完成事件传递，IEC61850中的一种快速报文传输机制
  - **直接广播**：一次消息同时被多个订阅设备接收，减少网络负担
  - **灵活性高**：无需点对点连接，提升系统可靠性和扩展性
- **类比**：UDP 广播，但带重传和序列号保证可靠性

### SV（Sampled Values）

- **模式**：发布者—订阅者（Publisher-Subscriber），以太网多播
- **用途**：传输模拟量实时采样数据（电流、电压）
- **特点**：
  - **高速传输**：支持高采样率（通常 80 点/周波，即 4000 Hz）
  - **网络共享**：采样数据在变电站内广播共享
  - **典型应用**：替代传统 CT/PT 接线，为继电保护和状态监测提供数据
- **类比**：网络化的 CT/PT 信号
![[Pasted image 20260713210737.png]]
- 模拟信号，数字信号 通过合并单元 使用SV服务 发送数字信号出去
![[Pasted image 20260713210917.png]]
- SV报文传输一次值，说明合并单元中有变比系数，如果合并单元故障恢复后可能变比重置会出问题






### 三种方式对比

| | MMS | GOOSE | SV |
|------|-----|-------|-----|
| 通信模型 | 客户端-服务器 | 发布-订阅（多播） | 发布-订阅（多播） |
| 传输层 | TCP/IP | 以太网（直连） | 以太网（直连） |
| 实时性 | 秒级 | <4ms | 微秒级同步 |
| 典型数据 | 配置、报警、遥测 | 跳闸、联闭锁命令 | 电流/电压采样值 |
| 可靠性机制 | TCP 重传 | 重复发送+序列号 | 重复发送 |
| BESS 应用 | PCS↔EMS 监控数据 | 保护联跳 | 暂无（储能低压侧通常用硬接线） |

## 6. 相对传统规约的优势

- **面向对象 vs 点表**：传统规约（Modbus、104）用寄存器/点表，61850 用逻辑节点和数据对象，语义明确
- **自描述**：SCL 文件使设备接入无需手动配点，即插即用
- **全站统一建模**：涵盖过程层、间隔层、站控层的完整信息模型
- **一网到底**：MMS/GOOSE/SV 共享同一以太网基础设施，降低布线成本
- **强扩展性**：新增设备只需更新 SCL 配置，不影响已有系统

---

## 7. 储能/BESS 场景关联

- **新建大储电站**越来越多采用 IEC 61850 作为站内通信标准
- PCS 通过 MMS 上送运行数据、接收调度指令
- GOOSE 用于储能保护联跳（BMS 保护 → PCS 紧急停机）
- 向调度主站通常仍用 IEC 104，站内用 61850
- 国内标准：GB/T 34120（储能变流器）参考了 61850 通信框架
