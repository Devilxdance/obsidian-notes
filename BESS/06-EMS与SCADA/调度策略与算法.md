# 调度策略与算法

## 常见策略

### 1. 峰谷套利
- 输入：分时电价 (TOU)
- 逻辑：谷充峰放
- 约束：SoC 范围、功率限制、充放电次数
- 优化目标：日收益最大化

### 2. 需量管理
- 适用：两部制电价用户 (基本电费 + 电度电费)
- 逻辑：监测需量，超出阈值时放电削峰
- 关键：需量周期 (15min 滑窗)
- 注意：防逆流控制

### 3. 新能源消纳
- 跟踪光伏/风电出力
- 余电存储，缺电释放
- 平滑波动 (ramp rate control)

### 4. AGC 调频
- 接收调度指令
- 秒级响应
- 精度考核 (Kp 值)

### 5. 防逆流控制
- 检测并网点功率方向
- 限制放电 / 充电 功率
- 快速响应 (秒级)

## 优化算法
- 规则策略 vs 数学优化
- 线性规划 / 混合整数规划
- 模型预测控制 (MPC)
- 机器学习 / 强化学习 (前沿)

## 策略设计考虑因素
- 电池寿命 (循环成本)
- 充放电效率损失
- 自耗电
- 运维周期
