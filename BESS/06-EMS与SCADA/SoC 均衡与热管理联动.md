# SoC 均衡与热管理联动

## SoC 均衡

### 均衡层级
- **Pack 内均衡** (BMS 被动 / 主动均衡)
- **簇间均衡** (Rack 间 SoC 差异)
  - PCS 独立控制每簇
  - DCDC 簇级均衡
- **堆间均衡** (多套 PCS 并联)

### 均衡策略
- 充电末端均衡
- 实时均衡

## 热管理

### 冷却方式
- 风冷 (小功率、成本敏感)
- 液冷 (主流，大容量)
- 浸没式液冷 (前沿)

### 热管理目标
- 电芯温差 < 3~5°C
- 最佳工作温度 25~35°C
- 低温预热 (<0°C 禁充)

### EMS 与热管理联动
- 温度越高 → 限制功率 → 保证安全
- 热管理策略优化 (预冷 / 随动)
- 自耗电优化

## SoH 估算与管理
- 容量衰减 vs 内阻增加
- 基于循环次数 / 日历时间
- 基于特征提取 (ICA / DVA)
