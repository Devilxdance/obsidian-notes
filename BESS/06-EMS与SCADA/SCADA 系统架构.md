# SCADA 系统架构

## SCADA 是什么
- Supervisory Control and Data Acquisition
- 数据采集与监视控制系统
- 储能电站的「眼睛」和「手」

## 与 EMS 的关系
| | EMS | SCADA |
|---|---|---|
| 核心 | 策略 / 决策 | 监视 / 控制 |
| 关注 | 经济性 (怎么跑最赚钱) | 安全性 (设备状态怎么样) |
| 颗粒度 | 电站级 | 设备级 / 间隔级 |
| 接口 | 调度 / 电力市场 | 保护 / 测控 |

> 实际产品中两者往往融合，统称 EMS/SCADA

## SCADA 核心组件
- **数据服务器** (实时库 + 历史库)
- **操作员工作站**
- **远动通信网关** (RTU)
- **Web 发布服务器**

## SCADA 功能
- 实时数据采集 (遥测)
- 状态监视 (遥信)
- 遥控 / 遥调
- SOE 事件顺序记录
- 历史趋势曲线
- 报表生成
- 权限管理

## 人机界面 (HMI)
- 一次系统图 (电气主接线)
- 单线图 / 光字牌
- 趋势曲线
- 告警窗
