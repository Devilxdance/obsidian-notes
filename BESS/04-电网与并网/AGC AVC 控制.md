# AGC AVC 控制

## AGC (自动发电控制)
- 全称：Automatic Generation Control
- 调度 → 储能电站 — 自动调节有功出力
- 控制模式：定功率 / 跟踪曲线
- 响应时间要求
- 调节精度要求

## AVC (自动电压控制)
- 全称：Automatic Voltage Control
- 调度 → 储能电站 — 自动调节无功出力
- 控制目标：并网点电压 (或功率因数)
- 无功源：PCS 无功能力 + 可能的 SVC/SVG

## 储能与调度通信
- 远动装置 (RTU)
- 调度数据网
- IEC 104 协议 (与调度通信)
