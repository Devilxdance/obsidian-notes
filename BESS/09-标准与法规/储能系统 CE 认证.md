# 储能系统 CE 认证

> 来源：学习笔记，系统梳理锂电池储能系统 CE 认证的适用指令、标准清单、测试项目与认证路径。

---

## 1. CE 认证总览

CE 认证本质是**合规性声明**（自我声明 + 第三方检测），需覆盖欧盟多项指令 + 对应的协调标准（EN/IEC）。

锂电池储能系统（ESS）需覆盖四大块：**安全 + EMC + 环保 + 电池专项**。

### 适用指令

| 指令 | 编号 | 适用范围 |
|------|------|----------|
| 低电压指令 LVD | 2014/35/EU | 50–1000Vac / 75–1500Vdc 电气安全 |
| 电磁兼容指令 EMC | 2014/30/EU | 不对电网或其他设备产生电磁干扰 |
| RoHS 指令 | 2011/65/EU | 限制有害物质（铅、镉、汞、六价铬等） |
| 电池法规 | (EU) 2023/1542 | 电池可追溯、回收、碳足迹、性能标签 |
| 机械指令 | 2006/42/EC | 含机电驱动单元或自动化搬运时适用 |

## 2. 标准体系 — 分层面

### 🔋 电池层面

| 标准 | 用途 | 关键测试 |
|------|------|----------|
| EN 62619 (IEC 62619) | **工业锂电池安全（储能必做）** | 短路、过充、跌落、热滥用 |
| EN 63056 (IEC 63056) | 户用储能电池安全 | 绝缘、过充、短路、防火防水 |
| EN 62281 (IEC 62281 / UN38.3) | **电池运输安全（全球强制）** | 高低温循环、振动、冲击、短路 |
| EN IEC 62933-5-2 | 电化学储能系统安全测试 | 电池安全测试方法 |
| EN 61427 | 电池性能与寿命 | 循环寿命、容量保持率、效率 |

### ⚡ PCS / 电力电子层面

| 标准 | 用途 | 关键测试 |
|------|------|----------|
| EN 62477-1 | 电力电子变流器安全 | 电气安全、过压/过流保护、绝缘耐压 |
| EN 61010-1 | 测量/控制设备安全 | 电气绝缘、防触电、温升 |
| EN 61000 系列 | **EMC 抗扰度/发射** | 静电放电、浪涌、谐波、电压闪烁 |
| EN 50549-1/-2 | **并网要求** | 并网稳定性、孤岛防护、电能质量 |

### 🏗 系统级（集装箱/柜体）

| 标准 | 用途 | 关键测试 |
|------|------|----------|
| EN 62933-2-1 | 储能系统整体安全 | 系统电气安全、隔离、接地、故障保护 |
| EN 62933-5 | 系统级安全测试 | 火灾防护、热失控传播、BMS 故障模拟 |
| EN 60204-1 | 机电安全 | 紧急停机、接地、绝缘 |
| UL 9540A (参考) | 热失控测试 | 电芯失效 → 模组 → 系统级火灾行为 |

### 🌍 环保法规

| 标准/法规 | 主要关注点 | 注意事项 |
|-----------|-----------|----------|
| RoHS (EN 50581) | 有害物质限值 | 关注 PCB、焊料、塑料外壳中的重金属/阻燃剂 |
| REACH (EC 1907/2006) | SVHC 化学物质声明 | 关注电解液、胶水、密封剂、涂层是否含 SVHC |
| EU Battery Reg. (2023/1542) | 电池回收、碳足迹、二维码追溯 | 2024 起逐步强制 |

## 3. CE 认证路径

```
步骤1 → 确定适用指令（LVD / EMC / RoHS / Battery Regulation）
步骤2 → 依据协调标准做型式试验（电池安全 + 电气安全 + EMC）
步骤3 → 编写技术文档（测试报告、风险评估、BOM 材料符合性声明）
步骤4 → 出具 EU Declaration of Conformity (DoC)，贴 CE 标志
步骤5 →（可选）找 NB（公告机构）做第三方认证（大型储能项目常要求）
```

## 4. 详细测试清单 — Cell / Pack / Container

### 🔬 01 Cell（电芯级）

| 标准 | 关注点 | 主要测试 |
|------|--------|----------|
| IEC 62619 | 工业电芯安全 | 过充、过放、短路、热滥用、机械冲击、振动、防火 |
| UN 38.3 | 运输安全 | T1-T8 共 8 项（高低温、振动、冲击、短路、过放） |
| UL 1642 | 锂电池安全 | 短路、异常充电、强制放电、挤压、冲击、热滥用 |

> IEC/UL 热失控传播测试：单电芯失效触发 → 模组/Pack/整柜逐级传播分析 → 验证热传播可控性

### ⚙️ 02 Pack（模组/电池包级）

| 标准 | 关注点 | 主要测试 |
|------|--------|----------|
| IEC 62619 | Pack 整体安全 | BMS 功能安全、整包短路、充放电过流、IP 防护 |
| UL 1973 | 固定式储能电池 | 电气性能、高低温循环、湿热、机械冲击、热滥用、BMS 功能、绝缘接地 |
| IEC 62485-5 | 工业电池安全 | 防触电、通风排气、电解液泄漏与防爆、接地防反接 |
| IEC 61000 系列 | EMC | 静电放电、辐射抗扰度、快速脉冲群、谐波闪烁 |
| IEC 62477-1 | 功率变换设备安全 | 电气隔离、绝缘与爬电距离、过温、热失控保护 |

### 🧱 03 Container（系统集装箱级）

| 标准 | 关注点 | 主要测试 |
|------|--------|----------|
| IEC 62933 系列 | 储能系统总体安全 | 系统安全设计、防火/防爆/隔离、紧急断电、控制系统 |
| IEC 62040-1 | UPS 安全 | 绝缘防触电、电气干扰、稳压性能 |
| NFPA 855 | 储能安装与防火 | 安装间距、通风、消防 |
| NFPA 69 | 防爆系统 | 防爆控制 |
| NFPA 68 | 爆炸泄压 | 泄压设计 |
| UN 1364 / UN 3536 | 运输分类 | 整套电池系统危险品运输申报 |

## 5. 三层级标准对照总表

| 层级 | 主要目标 | 关键标准 | 关注点 |
|------|----------|----------|--------|
| **Cell** | 电芯安全与运输 | IEC 62619 / UN38.3 / UL 1642 | 热失控、机械滥用 |
| **Pack** | 模组系统安全 | UL 1973 / IEC 62485 / IEC 61000 | BMS、电气与机械完整性 |
| **Container** | 系统安装与消防 | IEC 62933 / UL 9540 / NFPA 855 | 防火、防爆、热传播 |

---

## 6. BESS 实践要点

- **储能必做底线**：EN 62619（电池安全）+ EN 62477-1（PCS 安全）+ EN 61000 系列（EMC）+ UN38.3（运输）
- **并网项目追加**：EN 50549
- **出口欧盟**：RoHS + REACH + EU Battery Regulation 2023/1542（2024 起逐步强制，含碳足迹/可追溯）
- **大型项目**：建议走 NB 第三方认证，降低合规风险
- **北美市场**：UL 9540/9540A + NFPA 855 体系，与 CE 体系相互独立
