# 国标体系梳理

## 电化学储能核心国标

### 电池安全
- **GB/T 36276** — 电力储能用锂离子电池 (最关键标准)
- **GB 38031** — 电动汽车用动力蓄电池安全要求 (参考)
- **GB/T 34131** — 电化学储能电站用锂电池管理系统 (BMS)

### 储能电站设计
- **GB 51048** — 电化学储能电站设计规范
- **GB/T 42288** — 电化学储能电站安全规程
- **GB/T 42312** — 电化学储能电站生产安全应急预案编制导则

### 储能系统与设备
- **GB/T 36547** — 接入电网技术规定
- **GB/T 36548** — 接入电网测试规范
- **GB/T 34120** — 储能变流器技术规范

### 其他相关
- **DL/T 2528** — 电化学储能电站调试规程
- **DL/T 5810** — 电化学储能电站施工及验收规范
- **NB/T 33014 ~ 33016** — 接入配电网

## 强制标准 (GB) vs 推荐标准 (GB/T)
- GB：必须执行
- GB/T：推荐执行 (但合同/招标往往引用 → 事实上强制)

## 常见引用关系
- 招标文件 → GB/T 36276（电池） + GB/T 34120（PCS）
- 设计院 → GB 51048
- 电网接入 → GB/T 36547 + GB/T 36548
