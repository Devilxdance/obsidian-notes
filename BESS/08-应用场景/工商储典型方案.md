# 工商储典型方案

## 场景定义
- 工业用户 (工厂)
- 商业用户 (商场、写字楼、酒店)
- 接入：0.4kV 低压侧
- 典型规模：100kW / 200kWh ~ 2MW / 4MWh

## 主要收益模式
1. **峰谷套利**：谷电充电，峰电放电
2. **需量管理**：削峰填谷降低基本电费
3. **光伏消纳**：光伏余电存储
4. **备电**：部分场景保障用电

## 系统架构
- All-in-One 户外柜 (主流) vs 集装箱
- 直流耦合 vs 交流耦合
- PCS 功率：50kW / 100kW / 200kW
- 电池容量：100kWh ~ 400kWh / 柜

## 关键设计要点
- **防逆流**：CT + 防逆流控制器
- **并网审批**：发改备案 / 电网接入批复
- **电价政策**：各省分时电价不同，决定 IRR
- 噪音控制 (居民区)
- 散热 (户外柜)

## 开发流程
1. 收资 (负荷曲线、电费单、一次系统图、场地)
2. 方案设计 (规模测算、IRR 测算)
3. 备案审批
4. 设备采购
5. 安装调试
6. 并网验收
