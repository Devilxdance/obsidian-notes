## 📝 学习路线建议

```mermaid
graph LR
    A[AC 侧基础] --> B[电网与并网]
    B --> C[二次侧保护]
    C --> D[通信协议]
    D --> E[EMS 策略]
    E --> F[SCADA 系统]
```

1. **先补 AC 侧**：理解 PCS 怎么把直流变成交流，变压器怎么接，开关柜是干嘛的
2. **再补电网**：理解有功无功、频率电压这些基本概念，看懂并网标准
3. **然后二次**：保护怎么配，通信协议怎么传数据
4. **最后 EMS/SCADA**：策略怎么调，数据怎么采
