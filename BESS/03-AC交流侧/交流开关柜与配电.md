# 交流开关柜与配电

## 开关柜类型
- 高压开关柜 (10kV / 35kV)
  - KYN28A / KYN61 手车式
  - 充气柜 (SF6 / 环保气体)
- 低压开关柜 (0.4kV / 0.69kV)
  - GCS / MNS / GGD

## 核心元件
- **断路器** (VCB / ACB) - [[断路器选型]]
- **隔离开关**
- **CT (电流互感器)** / **PT (电压互感器)**
- 避雷器
- 接地开关

## 一次系统图
- 单母线 / 单母线分段
- 储能进线柜 → 计量柜 → PT 柜 → 馈线柜 → PCS

## 五防闭锁
- 防止误分误合断路器
- 防止带负荷拉合隔离开关
- 防止带电挂接地线 (合接地开关)
- 防止带地线送电
- 防止误入带电间隔
