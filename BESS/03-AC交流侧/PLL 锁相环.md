## 1. 基本概念

- **PLL（Phase-Locked Loop，锁相环）**：一种闭环反馈控制系统，使输出信号跟踪输入信号的相位和频率
- **核心组成**：鉴相器（PD）→ 环路滤波器（LPF）→ 压控振荡器（VCO）

```
输入信号 ──→ PD ──→ LPF ──→ VCO ──→ 输出信号
              ↑                       │
              └────── 反馈 ──────────┘
```

---

## 2. 在电力电子中的应用

- **电网同步**：从三相电压中提取电网电压的相位角 θ，实现与电网的同步
- **SRF-PLL（同步旋转坐标系锁相环）**：最常用的三相并网锁相环
  - Clark 变换：abc → αβ
  - Park 变换：αβ → dq
  - PI 调节 q 轴分量为零，锁定相位
- **SOGI-PLL（二阶广义积分器锁相环）**：适用于电网畸变/不平衡场景

---

## 3. 储能/BESS 场景关联

- **PCS 并网前提**：PCS 必须通过 PLL 精确锁定电网相位，才能实现同步并网
- **离网切换**：PCS 从并网切离网时，PLL 用于检测孤岛状态并快速切换控制模式
- **无功补偿**：PLL 提取的相位角用于 dq 解耦控制，实现有功/无功独立调节
- **低电压穿越（LVRT）**：电网故障时 PLL 的跟踪速度和稳定性直接影响 LVRT 性能
- **多机并联**：VSG（虚拟同步机）控制依赖 PLL 实现多台 PCS 的相位同步
