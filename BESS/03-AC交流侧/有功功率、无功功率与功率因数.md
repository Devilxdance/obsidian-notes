## 1. 有功功率（Active Power, P）

- **定义**：真正被负载消耗、做功的电功率，转化为热、光、机械能等。
- **纯阻性负载**：电流与电压 **方向相同、相位相同**，P > 0。
- **公式**：P = S = UI（纯阻性时），单位 **W（瓦）**。
- 在光伏电站中，有功功率是可被电网调度的有效出力。

---

## 2. 无功功率（Reactive Power, Q）

### 感性无功（电感负载）
- 纯电感中，电流 I 滞后电压 90°。
- 电感每个周期吸收 2 次能量、释放 2 次能量（储能 ↔ 释能），**不做功**。
- Q = S，单位 **var（乏）**。

### 容性无功（电容负载）
- 纯电容中，电流 I 超前电压 90°，恰好与电感抵消。
- 在负载侧并联电容可减少线损，实现无功补偿。

### 为什么要无功补偿？
- 无功功率本身不消耗能量，但实际线路 **有电阻**。
- 能量在线路中往返吸收/释放时产生 **线损（I²R）**，浪费发电机组发出的电能。
- 光伏电站无功补偿集中在：箱变、集电线路、升压站主变压器、送出线路。
- 无功需求一般占电站容量的 **10% ~ 30%**。

## 3. 视在功率与功率因数

| 符号 | 名称 | 公式 | 单位 |
|------|------|------|------|
| S | 视在功率 | S = UI | VA |
| P | 有功功率 | P = S·cosθ = S·λ | W |
| Q | 无功功率 | Q = S·sinθ | var |
| λ | 功率因数 | λ = cosθ = P/S | 无量纲 |

**功率三角形**：

```
       S（斜边）
      /|
     / | Q
    /θ |
   ────
     P
```

- P = S·cosθ = S·λ
- 相位角范围：-π/2 < θ < π/2
- **功率因数越接近 1，无功占比越小，线路损耗越低。**

---

## 4. 无功补偿基本原理

### 核心思想：电感电流与电容电流相位相差 180°，并联后抵消。

```
电感电流 I_L：滞后电压 90°
电容电流 I_C：超前电压 90°
→ 两者反相，并联后互相抵消
```

### 实际电力系统中的应用
- 电力系统中 **大部分负载是感性负载**（电机、变压器等）。
- 总电流 I 滞后电压一个角度 φ₁。
- 并联电容器后：I' = I + I_C，电容电流抵消部分电感电流。
- 总电流从 I 降至 I'，相位角从 φ₁ 减小到 φ₂。
- → 功率因数提高，无功就地平衡。

### 补偿示意

```
补偿前：cosφ₁ → P = UI·cosφ₁, Q = UI·sinφ₁
补偿后：cosφ₂ → 需要补偿的部分 = ΔQ
```

---

## 5. 储能/BESS 场景关联

- **PCS（储能变流器）** 可四象限运行，具备无功调节能力。
- 储能电站可通过 PCS 提供 **动态无功支撑**，参与电压调节。
- 相关标准：GB/T 34120（储能变流器技术规范）对功率因数有明确要求。
