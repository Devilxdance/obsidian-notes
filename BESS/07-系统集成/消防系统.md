# 消防系统

## 消防标准
- GB 51048 (电化学储能电站设计规范)
- GB/T 42288 (电化学储能电站安全规程)
- NFPA 855 (国际)

## 多级消防体系
1. **一级：电芯级** — BMS 监测 + 被动抑制 (防爆阀)
2. **二级：Pack 级** — 气溶胶 / 细水雾
3. **三级：舱级** — 全淹没气体 (全氟己酮 / 七氟丙烷) + 水喷淋
4. **四级：站级** — 消火栓 + 消防水池

## 消防联动
- 火灾探测器 (烟感 / 温感 / 可燃气体)
- 消防主机
- 与 BMS / EMS 联动
- 切断电路 + 启动灭火

## 防爆设计
- 防爆泄压口
- 隔爆墙 / 防爆间距
- 可燃气体排放
